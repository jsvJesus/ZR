# Деревья SpeedTree

Откройте готовую карту и выберите `Level editor → Растительность`.

1. Найдите дерево в каталоге и выберите его. Каталог построен по файлам
   `bin/packs/speedtree/**/*.ctree`; prefab не читаются и не используются.
2. Включите «ЛКМ — расставлять выбранное дерево» и щёлкайте по Terrain.
   Масштаб и поворот берутся из полей панели; «Применить параметры» обновляет
   их для следующих щелчков. После размещения дерево появляется в списке уровня.
3. Для выбора уже поставленных деревьев снимите флажок расстановки и щёлкните
   дерево либо выберите его в списке. «Показать выбранное» подводит камеру.
4. Измените координаты, масштаб или поворот и нажмите «Применить параметры».
   При включённой привязке Y означает смещение от текущего Terrain; без неё —
   абсолютную высоту. «Поставить на Terrain» возвращает привязку с нулевым смещением.
5. «Удалить выбранное дерево» удаляет только экземпляр уровня.
6. «Сохранить растительность» или `File → Сохранить уровень` записывает
   `bin/packs/levels/<имя>/vegetation.json`. Применённые изменения также сохраняются
   при смене карты и обычном закрытии редактора. Файлы моделей и DDS не изменяются.

Загрузка: 287 CTREE105 из текущего набора. Файл SPT разрешается через соседний
готовый CTREE; генерация геометрии из SPT без CTREE не реализована.
Reader напрямую читает ветви, fronds, листву, LOD, пути diffuse/normal и служебный
billboard-блок. Исходные индексы используются без преобразования: triangle strip
для ветвей/fronds, triangle list для листьев. Формат основной сериализации
сопоставлен с [TreePartRenderData::read в исходном BigWorld](https://github.com/v2v3v4/BigWorld-Engine-1.9.1/blob/master/src/lib/speedtree/speedtree_renderer_util.hpp).
Особенности CTREE105 (checksum и billboard stride20) сверены с локальными файлами.
Границы из заголовка отражаются по Z в систему сохранённой геометрии и расширяются
по вершинам/карточкам для выбора мышью.

DX11 использует общий меш и текстуры для экземпляров одной модели, исходные
геометрические LOD, alpha test листвы и карточки, обращённые к камере.
При включённой привязке основание дерева следует текущей подробной/обзорной сетке
Terrain, а сохранённый HeightOffset добавляет ручное смещение. Это предотвращает
зависание или погружение основания при переключении детализации.
В Play деревья видны, а редактор расстановки отключён. Ветер SpeedTreeRT,
плавные переходы LOD, дальние billboard-модели, физические столкновения с деревьями
и тени деревьев пока не подключены. Освещение использует шейдер редактора.

Статически разобраны все 287 CTREE и их индексы; все указанные DDS присутствуют.
DDS набора имеют DXT1, DXT3 и DXT5, поддержанные общим загрузчиком.
Ни сборки, ни тесты, ни запуск редактора для проверки этой реализации не выполнялись.
