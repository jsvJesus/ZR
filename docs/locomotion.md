# Locomotion персонажа

Ресурсы: `bin/packs/characters2/basemodel/StalkerBase2.model` и указанные в нём
файлы `.animation`. Реализация: `src/World/Characters/Locomotion`.

## Поворот на месте

Порог запуска и шаг поворота — 45° для обеих поз. Настройки находятся в
`LocomotionSettings`. Большой разворот выполняется несколькими шагами без
промежуточного переключения на idle; движение прерывает поворот.

Используются исходные действия `turn_left45_stay_incombat`,
`turn_right45_stay_incombat`, `turn_left45_crouch_unarmed` и
`turn_right45_crouch_unarmed`. Стоячих клипов 45° с именем `stay_unarmed`
в модели нет. Боевые клипы накладываются на безоружный idle с наследованием
`NodePriority`: Root/Pelvis участвуют в повороте, Hips и его верхняя ветвь
берутся из базовой позы. Поворот Root извлекается в контроллер один раз.

Оригинальные настройки поворотов находятся в
`sdk/scripts/client/new_turn.pyc_dis`; порог и шаг 45° — изменение по запросу.

## Переходы и движение

Скорости берутся из `player_speed_settings.pyc_dis`, а диапазоны выбора,
темп, события ног и время смешивания — из модели. В пересекающихся угловых
диапазонах сохраняется текущее направление той же походки. Смена скорости
по-прежнему выбирает walk/run/sprint по порядку действий в модели.

Во время движения направление тела следует камере. При повороте камеры
текущая скорость переводится в новую систему направлений до ускорения,
поэтому вращение камеры само по себе не включает бег боком/назад и не
сбрасывает спринт. Повороты на месте по 45° обрабатываются отдельно.

Фаза при смене движущихся клипов сопоставляется по событиям левой/правой
ноги. Источник смешивания вычисляется на момент перехода, включая переходы
между физическими подшагами. Root остановок и приземления применяется к
положению персонажа, а затем удаляется из позы.

Разбеговый прыжок использует подъём Root и `isIgnorGravity` исходного клипа;
после отталкивания включается падение. Горизонтальные смещения физики и
анимации выбираются по большей длине, согласно `vel_or_imp`, без сложения.
Прыжок с места сохраняет физический импульс: его клип не содержит подъёма Root.
Фазы и задержки приземления заданы по `animation_jump_config.pyc_dis`.

W при наличии разбега выбирает `run_jump_*` с левой или правой ноги.
A/D/S и прыжок с места используют отдельный комплект `idle_jump_*`.
Для A/D/S горизонтальная скорость сохраняется при отталкивании; обнуление
применяется только при отсутствии ввода движения. Обычное приземление
`idle_jump_down__unarmed` доигрывает диапазон из модели (20 кадров при 30 fps),
а не обрывается общим таймером 0,4 с. Варианты прыжков не унифицированы.

## Границы проверки

Проверка выполнена чтением исходников, статическим разбором ресурсов и ревью
изменений. Тесты, приложения и сборки не запускались. Визуальное поведение
требует проверки в Play. Исходники C++ ActionMatcher из оригинального движка
здесь отсутствуют, поэтому полная идентичность его поведения не подтверждена.
