# Чтение и размещение SpeedTree

Цель: читать деревья из packs/speedtree и расставлять их на готовых уровнях.
Никаких prefab. Оригинальные файлы не менять и не конвертировать.
Не создавать и не запускать тесты, сборки и приложения; только статическая проверка.

- [ ] World/Vegetation: каталог CTREE/SPT; прямой reader CTREE105, границы,
  ветви/fronds/leaves, LOD и пути DDS; отдельные данные экземпляров и атомарное сохранение.
- [ ] DX11: общий GPU-меш на тип дерева, карточки листвы раскрываются в шейдере,
  alpha test, выбор LOD, подсветка, освобождение ресурсов при смене уровня.
- [ ] Viewport: луч из курсора, попадание в видимую поверхность Terrain,
  размещение экземпляра и выбор существующего дерева.
- [ ] Панель Растительность: поиск по каталогу, размещение, список экземпляров,
  координаты/поворот/масштаб, удаление, сохранение. Блокировка при Play/смене карты.
- [ ] Подключить загрузку vegetation.json и сохранение при File Save, смене карты,
  закрытии. Проверить исходники/API/ссылки и diff без запуска кода приложения.

Инвентаризация: 287 CTREE105, 287 SPT, все текстуры CTREE существуют.
CTREE105: version+source checksum, bbox6float, leafRock/leafRustle2float.
Branch/frond stride64, leaf stride100. Индексы uint32: triangle strips для
ветвей/fronds и triangle lists для листьев. Billboard-cache: старый LOD-блок,
stride20(position+UV), uint16 strips; в найденных файлах billboard vertices
обычно уже triangle list. Размещение использует геометрию основных частей;
ветер SpeedTreeRT и его плавные LOD-переходы в этот этап не входят.
