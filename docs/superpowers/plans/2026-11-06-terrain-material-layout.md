# Исходные участки материалов FBX

Уточнение пользователя: выбрать собственное изображение материала и сразу увидеть его
на всех исходных участках Terrain, без ручной покраски. Предыдущая реализация перенесла
только палитру и не сохранила распределение материалов по треугольникам.

Решение: спроецировать индексы материалов верхней поверхности FBX в существующие
маски Terrain с тем же масштабом, ориентацией и SourceOffset, что у импорта высот.
Сохранять признак перенесённого распределения. Новый импорт включает его автоматически;
старый Escape получает его при импорте материалов или первом назначении изображения.
Повторная замена изображения меняет материал на всех его участках без пересчёта масок.
Высоты, отверстия и объекты не изменяются. Явное восстановление исходных участков
отменяется одной операцией. Рисование остаётся отдельным дополнительным режимом.
Размер повторения изображения остаётся существующей настройкой материала в метрах;
это перенос участков материалов на heightfield, без исходной UV-развёртки меша.

- [x] Подключение нового импорта и существующего Escape.

- [x] Документация, статический разбор и ревью.

Проверено статически: Roslyn разобрал 30 изменённых/новых C# файлов без ошибок
синтаксиса, git diff --check прошёл. Ревью подтвердило соответствие координат масок
шейдеру и исходному растру высот, применение/отмену и сохранение ревизий. Исправлены
выбор только верхнего каталога FBX (как при импорте высот) и сохранение индекса
материала при переносе исходного FBX/рабочей папки. Повторная проверка этих исправлений
не выявила блокирующих замечаний. Пользовательские ассеты Escape не записывались.

Тесты, сборки, запуск редактора и запись пользовательских ассетов запрещены в рамках проверки.
