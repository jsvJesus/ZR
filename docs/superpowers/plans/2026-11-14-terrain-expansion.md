# Обновление Terrain из расширенного FBX

Пользователь подтвердил: старая часть FBX не сдвинута и не масштабирована; новую
землю добавлять также в пустые внешние края, внутренние отверстия сохранять.

## Решение

Новая кнопка расширяет текущий сохранённый Terrain. Старая земля, внутренние отверстия,
ручные высоты, маски и свойства материалов сохраняются. Внешняя пустота определяется
как отверстия, соединённые с границей старой карты. Новые участки берутся из FBX.
Сетка сохраняет шаг и выравнивается по старым тайлам. OriginX/Z позволяет расширение
во все стороны без перемещения объектов, камеры, водоёмов и дорог.

До применения сохраняются текущие правки. Новый набор Terrain записывается в отдельный
каталог; level.json переключается последним. Создаётся полная резервная копия уровня.
Обновление не запускается инструментами агента над Escape, только реализуется кнопка.
Нормали/обзор пересчитываются. Если новые высоты выходят за диапазон, расширяется
диапазон 16-битного хранения (погрешность старых высот ограничена новым шагом квантования).
Старые изображения/PBR/варианты/иерархия слоёв сохраняются; новые материалы добавляются.

## Проверка и решения ревью

- Отдельно проверены объединение/запись и интеграция Origin CPU/GPU.
- Маски сохраняют полный диапазон влияния линейной фильтрации и собственные границы старых тайлов.
- Свойства существующих слоёв восстанавливаются целиком после поиска соответствий исходных материалов;
  меняются только масштаб нормализованных UV для сохранения размера повторения и идентификатор источника.
- Неполные резервные копии удаляются с проверкой пути; ошибки удаления сообщают путь.
- Ошибка открытия после commit блокирует сохранение старого документа до перезапуска.
- Привязки сгенерированных деревьев к тайлам пересчитываются при загрузке без перемещения деревьев;
  seed/ID используют мировые тайлы, чтобы сохраняться при расширении в отрицательные стороны.
- Отмена после commit также оставляет блокировку до повторного открытия, без ложного сообщения об откате.
- Фактическое обновление Escape, запуск редактора, тесты, сборки и компиляция шейдеров не выполнялись.
- Итоговый Roslyn-разбор 27 изменённых/новых C# файлов: 0 синтаксических ошибок.
  git diff --check прошёл; изменений в packs/levels, packs/import и packs/backups нет.
  Повторное ревью исправлений объединения/сохранения и независимое ревью Origin
  не выявили оставшихся блокирующих замечаний.
