# Выравнивание и привязка моделей к Terrain

Пользователь запросил инструмент выравнивания и следование моделей за рельефом, затем поручил продолжить без дополнительных вопросов.

- Выравнивание добавляется в список инструментов. Высота первого успешного касания фиксируется на весь мазок; сила 0–1, радиус существующий, мягкий край кисти.
- Существующие и новые модели следуют за высотой земли по умолчанию. В свойствах экземпляра есть отключаемая привязка.
- Выбранный способ: высота Terrain под центром границ модели, движение только по Y с сохранением исходного смещения, поворота и масштаба. Сохранённая опора предотвращает накопление ошибок при мазках и отмене. Служебные невидимые коллизионные оболочки не перемещаются.
- Альтернативы: привязка только отмеченных моделей или наклон по нормали. Первый вариант не реализует ожидаемое автоматическое поведение; второй нежелателен для домов.
- Изменение рельефа и его отмена перепроецируют привязанные модели. История ручных правок объектов сохраняется и учитывает текущий рельеф.
- Привязка сохраняется в objects.json с чтением прежних версий. Сохранение Terrain и объектов согласовано на уровне команд редактора.
- При отверстии/отсутствии поверхности опора не меняется. Импорт новой геометрии Terrain из FBX не относится к мазкам кисти.
- Ограничения проекта: не создавать/не запускать тесты или тестовые приложения; не запускать сборки. Проверка исходников и статический разбор.
