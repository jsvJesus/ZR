# Импорт уровней и Terrain

Пользователь подтвердил преобразование оригинальных уровней в собственный формат.

## Требования
- Источники: `bin/packs/import/levels/<имя>/`, только чтение.
- Результат: `bin/packs/levels/<имя>/`.
- Текстуры: общая библиотека `bin/packs/materials/`, без дублирования.
- В новых названиях, интерфейсе и документации используется только Terrain.
- Небольшие файлы с одной ответственностью и тематическими подпапками.
- Не запускать сборку, тесты или приложение. Разрешены чтение исходных файлов и статическая проверка изменений.

## Подход
Выбран отдельный импортёр: исходные бинарные данные преобразуются один раз,
редактор открывает собственный формат. Прямое чтение оригиналов при каждом
открытии отклонено пользователем в пользу разделённых import/levels и levels.

Общая библиотека World содержит модели уровня, хранение, чтение материалов,
DDS и исходных данных Terrain. Она не зависит от графического API.
Editor содержит операции импорта/открытия и ресурсы DX11 для отображения.

## Формат
`level.json`: версия, имя, параметры Terrain, список чанков и камера.
`layers.json`: упорядоченные слои и относительные пути к материалам.
`terrain/`: отдельные файлы высот, нормалей и покрытия по чанкам.
`import.json`: происхождение, время, статистика и сообщения импорта.

Импорт выполняется во временную соседнюю папку, готовый уровень публикуется
только после завершения. Существующий результат не перезаписывается молча.
Неизвестные версии и неполные данные дают понятную ошибку.

## Отображение
Чанки Terrain отображаются с исходным покрытием и материалами, с буфером
глубины. Геометрия выбирается с учётом расстояния; ресурсы имеют ограниченный
кэш. Редактирование высот и покраска относятся к следующей функции;
первый результат — импорт и просмотр трёх имеющихся уровней.

## Особенности данных
Arizona и Aspen имеют сетку 4096×4096, California — 8192×8192.
У каждого источника 64 чанка. INI является общим источником настроек для
всех карт. Бинарная структура устанавливается по реальным файлам перед
реализацией декодера; приблизительное покрытие не считается импортом.
